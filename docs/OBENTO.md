# おべんとう はんぶんこ（js/games/obento.js）

おかずを2つの皿に分けて、相手が先に選ぶ。もらったおかずを自分の弁当箱に詰める2人用パズルです。

- **2人**：それぞれのスマホで対戦。**1人**：コンピュータと対戦。**3人目から**：観戦（「もう一回」で、負けた人と次の人が交代）。
- 同じ2人で「もう一回」をすると、1回目に分ける人（あかい弁当箱）が交代します。
- ルールは、ゲームのカードの「ルールを見る」と、ゲーム中の上の帯の「📖 ルール」から見られます。

## ルール（約3分）

- 4×6マスの弁当箱に、5回に分けておかずを詰める。
- 毎回おかずが4つ出る。**分ける人**が2つの皿に分け、もう1人が**先に好きな皿を取る**。残りが分ける人の分。
- 分ける人は**そのとき点が多い方**（同点なら交代。1回目はあかい弁当箱）。先に選ぶ方が1回あたり約1点得なので、追いかける方が先に選べる。
- もらったおかずは2人同時に自分の箱へ。マスを押すと、そこに入る向きで置ける（「回す」で向きを選べる）。入らないおかずはあきらめる。
- 1マス1点。点になるのは**ごはん12・主菜4・副菜8マスまで**（主食:主菜:副菜＝3:1:2）。
- **すき間なし**（24マス全部）で+3。**彩り★**：縦1列に3色以上で1列ごとに+1。
- **きょうのリクエスト**：6枚から毎回2枚。満たしたら1枚+3（2人とももらえる）。「ごはん少なめ」だけは最後に判定。
- 5回終わって点が多い方の勝ち。同点なら空きマスが少ない方。

| おかず | 種類 | 色 |
| --- | --- | --- |
| ごはん | 主食 | 白 |
| からあげ／たまご焼き | 主菜 | 茶／黄 |
| ブロッコリー／ミニトマト | 副菜 | 緑／赤 |

| リクエスト | 条件 |
| --- | --- |
| からあげ好き | からあげが3マス以上 |
| たまご焼き好き | たまご焼きが3マス以上 |
| トマト好き | トマトが3マス以上 |
| やさい多め | ブロッコリーが5マス以上 |
| おにぎり2こ | ごはんで2×2の四角を2つ（重ならない） |
| ごはん少なめ | ごはんを8マスまで（最後に判定） |

## しくみ

- ファイルの中の `Ben` がルールとコンピュータです。設計ループ（案出しと改良ループ）の最終版 v8 と同じ点の数え方・リクエスト・分ける人の決まり・コンピュータの考え方で、ホストのスマホだけが `step()` でこれを動かします。
- 分ける・選ぶの入力は `{ rd: 回, ph: "split" | "choose", m | k }`。詰める入力はその回に置いた全部の列 `{ rd: 回, pl: [{ i, r, x, y } | { i, drop: 1 }] }` を毎回まるごと送り、ホストは `d.pc[席]`（反映した数）の続きから順に確かめて反映します。自分の画面には、まだ届いていない分も先に反映して見せます。
- 画面は「相手の弁当箱（小）」「番の表示」「テーブルクロスの上：分ける・選ぶ、リクエスト、このあと出るおかず」「自分の弁当箱（大）と手札」の順。
