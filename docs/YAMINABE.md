# やみ鍋（js/games/yaminabe.js）

伏せた具の名前を言って鍋に入れる、うそOKの2人用カードゲームです（ルール第6版）。

- **2人**：それぞれのスマホで対戦。**1人**：コンピュータと対戦。**3人目から**：観戦（「もう一回」で、負けた人と次の人が交代）。
- 先手は「もう一回」のたびに交代します。

## ルール（約3分）

- 番には3つのうち1つ。**入れる**：手札1枚を伏せて鍋へ、具の名前を言う（うそOK）。**いただきます**：鍋が2枚以上なら（手札がない人は1枚でも）全部を表にして取り皿へ。**味見**：おたまで相手の具を1枚見る（1人2回）。
- 味見でうそを見つけたら「うそだ！」。その具は、見つけた人が自分か相手の取り皿を選んで入れる。
- 鍋が4枚なら、次の人は必ずいただきます。パスは手札がない人だけ。
- しめの雑炊（+5）は山札の底。引いたら表で持ち、表で入れる。
- 2人とも手札がなくなったら終わり。残りの鍋は、それぞれ自分の具を自分で食べる。先手はお通しのきのこ（+2）から。とうがらしは1枚−3点。点が同じなら、とうがらしが少ない人の勝ち。

| 具 | 点 | 枚数 |
| --- | --- | --- |
| 🥩 肉 | +4 | 4 |
| 🦐 えび | +3 | 5 |
| 🍄 きのこ | +2 | 7（1枚はお通し） |
| 🥬 はくさい | +1 | 6 |
| 🌶️ とうがらし | −3 | 8 |
| 🍚 しめの雑炊 | +5 | 2（山札の底） |

## しくみ

- ファイルの中の `Yami` がルールとコンピュータです（単体版と同じコードで、変えていません）。ホストのスマホだけが `step()` でこれを動かします。
- 画面は「暗がりで光る土鍋」（真上から）・言った言葉が残る会話・手札と返事の候補、の3段。鍋の枚数で湯気と明かりが強まり、4枚でぐらぐら揺れます。
- 効果音は13種をその場で合成します（音声ファイルなし）。それぞれのスマホで、届いた出来事に合わせて鳴ります。音の大きさは 切・小・中・大（右上のボタン、またはルール画面）。最初に画面を触ってから鳴ります。iPhone は消音スイッチがオンだと鳴りません。

| 音 | 鳴るとき |
| --- | --- |
| ぽちゃ＋泡 | 鍋に入れたとき（鍋の枚数だけ泡が増える：コトコト→ぐつぐつ） |
| ポーン | いただきます（続けて1枚ずつ表に返す音） |
| 上がる音／ジュッ | おいしい点が入った／とうがらしが入った |
| ピロッ | おたまで味見 |
| ブブッ | 「うそだ！」 |
| ピッ | 自分の番になった |
| ファンファーレ／下がる音 | 勝ち／負け |

## 気をつけること

- ほかのゲームと同じく、ゲームの状態は部屋の全員に届きます。画面には自分の手札しか出しませんが、ブラウザの開発ツールで通信をのぞけば相手の手札が分かります（友だち同士で遊ぶ前提）。
