# 山分けの掟（js/games/yamawake.js）

ひとりが分けて、ひとりが選ぶ。宝箱の中身を知っているのは、分けた人だけ。うそOKの2人用・海賊の山分けゲームです（約10分）。

- **2人**：それぞれのスマホで対戦。**1人**：コンピュータと対戦（コンピュータもうそをつきます）。**3人目から**：観戦（「もう一回」で、負けた人と次の人が交代）。
- 「もう一回」は掟どおり**負けた人が先手**。
- ルールは、ゲームのカードの「ルールを見る」と、ゲーム中の「📖 ルール」から見られます。

## ルール（約2分半）

- **準備**：宝石25個（赤・青・緑・黄・白×5個。色ごとに形も違う）とドクロ5個を袋へ。注文の石を1個ずつこっそり見る（自分の**注文**の色）。残りから1個を表に（**今日の相場**）。
- **流れ（全6回）**：分け手の順は **後・先・先・後・後・先**（航海日誌の枠の字）。分け手でない人が選び手。
  1. 分け手は袋から5個引き、相手に見せずに**1個を宝箱に入れる**。
  2. 残りの4個と宝箱を、綱の左右に分ける（どちらも1つ以上）。
  3. 選び手は3つの質問「宝箱にドクロを入れた？」「宝箱の中身は何色？」「きみの注文は何色？」から1つだけ聞ける。**答えはうそでもよい**。
  4. 選び手が左右どちらかの山を取る。残りは分け手のもの。宝箱はもらった人の航海日誌へ。中身は最後まで開けない。
- **決算**：宝箱と注文を全部開ける。同じ色3個以上で**首飾り＝金貨3**。その色が自分の注文なら**+2**、今日の相場なら**+1**。ドクロは1個**−1**。
  二人の合計はいつも奇数（首飾り5つで15、相場で1、ドクロ5個で−5、注文は2ずつ）なので、**同点にはならない**。

## 画面

- 上から：回・今日の相場・自分の注文 → 番の表示 → 相手（手元の宝石と航海日誌）→ 掟の板（綱の左右の山）→ 会話（分け方・質問・答えが残る）→ 自分 → 操作。
- 分け手は「宝箱に入れる1個を押す → ふたをする → 押して左右に動かす → この分け方で出す」。選び手は質問を選び、光っている山を押して取る。
- 自分が入れた宝箱には、自分の画面にだけ中身が小さく出ます（相手の画面には出ません）。

## しくみ

- ファイルの中の `Y` がルールとコンピュータです。ホストのスマホだけが `step()` でこれを動かします。
- コンピュータは、残りの石から「首飾りになる確率」で数え、相手がどちらを選ぶかを読んで分けます（設計時のシミュレーションの「強いAI」と同じ考え方）。

## 設計の資料（docs/yamawake/）

課題「ふたりで囲む、15分の対戦ゲーム」に向けて、3案の比較と8回の改良ループ（盲検の評価者2人＋AI同士1000局のシミュレーション）で作りました。

| ファイル | 中身 |
| --- | --- |
| [01_rulebook.pdf](yamawake/01_rulebook.pdf) | ルールブック（部品・準備・遊び方・決算・作り方） |
| [02_scenes.pdf](yamawake/02_scenes.pdf) | 遊んでいる場面と1局の記録 |
| [03_fun.pdf](yamawake/03_fun.pdf) | このゲームの面白さ（短い文） |
| [04_design_summary.pdf](yamawake/04_design_summary.pdf) | 設計まとめ（考え方・改良の歩み・数値・評価と課題） |

シミュレーションの主な数値（AI同士1000局）：先手勝率 48.2%（弱いAI同士 50.0%）、残り3手番でリードしていた側が負けた局 45.8%、最後の手番の選び方で勝敗が変わり得た局 43.5%、推定プレイ時間 約8.5分。

## 気をつけること

- ほかのゲームと同じく、ゲームの状態は部屋の全員に届きます。画面には自分の秘密（自分が入れた宝箱の中身・自分の注文）しか出しませんが、ブラウザの開発ツールで通信をのぞけば分かります（友だち同士で遊ぶ前提。やみ鍋と同じ）。
